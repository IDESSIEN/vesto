1. Design Philosophy

Top-tier UI is the ruthless removal of everything default. Not the addition of clever effects — the removal of every decision that was not made consciously. Vesto should feel expensive, trustworthy, and specifically itself. Never generic DeFi. Never AI-generated. Never safe.

Design principle

Vesto's visual identity is grounded in three tensions held in balance:

  • Warmth vs. precision: Parchment canvas and cream surfaces create warmth. JetBrains Mono tabular numerals and tight letter-spacing create precision. Neither overwhelms the other.
  • Restraint vs. character: Most of the app is clean, receded, and systematic. Then the cinema-ticket card breaks the system. The dark editorial panel breaks the system. These deliberate breaks create character.
  • Trust vs. momentum: Financial interfaces must earn trust through density, accuracy, and transparency. But they must also create momentum — the feeling that progress is happening. Progress steps, live status dots, and spring-eased transitions carry this.

Gold scarcity rule: Gold appears on: primary CTA buttons, the top strip of dark panels, tier badges, active yield values, and the cinema-ticket card strip. Nowhere else. Every additional gold element dilutes it.

No pure black, no pure white, no neon: #000000 and #FFFFFF never appear in the UI. Pure black feels cheap; pure white looks clinical. The warmth of #F8F6F1 is the emotional foundation.

Optical adjustment: Mathematical grids produce spacious but dead layouts. Tighten spacing between related elements (label → value: 4px). Open spacing between unrelated groups (card → card: 12px; section → section: 28–40px).

6. Screen-by-Screen Direction

Seller DashboardSeller

First 2 seconds: The balance number. Everything else is secondary. The cinema-ticket hero must dominate the viewport before the fold.

  • Balance hero: full width, dark gradient, perforation dots, balance number at clamp(44px, 9vw, 66px)
  • Stat tiles (3-col): top accent strip colour-codes the stat (green = escrow, gold = on market, purple = settled)
  • Progress checklist: compact, numbered, single action per step — never crowded
  • Invoice ledger: lifted tab selector. Rows: accent strip left border encodes status colour
  • Empty state: contextual. "Submit your first invoice to get a cash advance." with inline CTA. Not a generic empty-box icon.
Submit InvoiceSeller

First 2 seconds: The headline. "Turn unpaid invoices into immediate cash." Then the payout breakdown ribbon at the bottom before submit.

  • Form sections are cream cards with E1 shadow — clearly distinct from canvas
  • Money input: leading $ prefix fixed, JetBrains Mono bold, larger than surrounding fields
  • Upload zone: dashed border turns gold on upload; file icon becomes check
  • Payout breakdown: dark cinema panel, horizontal bar visualisation per row, perforation before net payout hero number
  • Credit limit error: red input field + inline copy explaining upgrade path — never a modal alert

7. Interaction Principles

Press Affordance

Every interactive element must have active:scale-[0.97] on press. This is the single most important interaction tell that separates premium from generic. Duration: 150ms. Never bounce or overshoot (cubic-bezier(0.22,1,0.36,1) spring, not elastic).

Motion Tokens

TokenValueUsed on
--ease-springcubic-bezier(0.22,1,0.36,1)Card hover lift, tab transition, modal entry
--ease-outcubic-bezier(0.0,0,0.2,1)Bar fills, progress indicators
--ease-in-outcubic-bezier(0.4,0,0.6,1)Loading spinners, skeleton pulses

Empty States

Every empty state must be: (1) contextual — explain WHY it's empty and what action will fill it; (2) specific — mention real numbers or timeframes when available; (3) actionable — include a single CTA when there is an obvious next step.

Loading States

Balances and onchain values loading: skeleton block (.skeleton-dark on dark panels, .skeleton on light). Width matches the expected content width. Never show "Loading..." text. The skeleton shape sets expectations about what will appear.

8. What NOT to Do

Remove immediately if found

  • Material Symbols / Google Icons — any <span class="material-symbols-outlined"> is a fingerprint. Use inline SVG only.
  • rounded-2xl by default — Tailwind default. Every element using it looks like every other AI-generated app.
  • Blended APY — showing "14% APY" without splitting out the platform fee hides information and destroys trust.
  • Generic empty states — "Nothing here yet" with a grey box icon. Contextual copy only.
  • focus:ring-2 focus:ring-primary — the default wagmi/ConnectKit focus ring is a blue outline. Use Vesto-token focus rings.
  • h-12 input height — the Tailwind default. Use custom heights that fit the typographic context.
  • shadow-md / shadow-lg — use the E1–E4 token system. Generic Tailwind shadows look flat and equal.
  • bg-gray-100 / text-gray-500 — warm neutrals only. Cold grays break the parchment identity.
  • Gradient text — webkit-background-clip gradients on headings are an AI staple. Plain ink on canvas.
  • Emoji in UI — no emoji anywhere in the product. SVG icons only.

Always present

  • Tabular numerals on every money value
  • Letter-spacing -0.025em or tighter on all headings over 15px
  • Left border accent on every status card (3px, colour = status)
  • Gold strip as the first child of every dark editorial panel
  • Grain overlay on every dark panel (not on light surfaces)
  • active:scale-[0.97] on every interactive element
  • Contextual copy on every empty state
  • Split yield display (gross / fee / net) wherever yield is shown
