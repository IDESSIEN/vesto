3. V2 & V3 Roadmap

V2 (3–9 months: Jan–Jun 2027) — Scale

  • Institutional lender onboarding: Whitelisted lender pools with dedicated allocation limits. KYC at the institutional level. Reporting dashboards.
  • Multi-chain USDC via CCTP: Lenders on Base, Arbitrum, and Polygon can fund Arc invoices. Frontend: Circle Bridge Kit integration.
  • Pooled capital allocation: VestoPool.sol ERC-4626 vault. Multiple lenders share a pool. Risk-weighted allocation algorithm runs off-chain.
  • Yield accrual ledger: Per-invoice, per-lender yield tracking. Auto-reinvest engine: claimed yield immediately allocated to next available invoice.
  • Mobile-responsive hardening: Full QA pass on mobile devices. Touch targets, scroll behaviour, keyboard avoidance on forms.
  • API access for institutional lenders: REST API for programmatic invoice browsing, funding, and portfolio reads. Rate-limited, API-key authenticated.

V3 (9–18 months: Jul 2027–Mar 2028) — Protocol

  • Tokenised invoice NFTs (ERC-1155): Each funded invoice mints fractional position tokens. Enables partial funding and secondary market.
  • Secondary market: Lenders can list and trade invoice position tokens. Order book on Arc. Settlement in USDC.
  • On-chain credit scoring: Soul-Bound Token (ERC-5192) attesting repayment history. Score improves advance rate and credit limit automatically without admin action.
  • VESTO governance token: Protocol parameter voting. Fee tier adjustment, pool allocation weight governance. Token distribution to early sellers and lenders.
  • ERC-8004 agent identity: Lender agents registered in the Arc identity registry. Programmatic invoice funding by autonomous agents.
